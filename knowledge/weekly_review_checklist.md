# 周末复盘清单

> 来源：@黄阳的学习分享 投资体系
> 核心原则：凡事预则立，不预则废，禁止盘中临场决策
> 执行时间：每周日收盘后

---

## 一、持仓检视

### 1.1 基本面变化检查
- [ ] 各持仓公司本周是否有重大公告？
- [ ] 业绩预告/财报是否发布？是否符合预期？
- [ ] 行业政策是否有变化？
- [ ] 公司内在价值是否发生变化？

### 1.2 估值状态检查
对每只持仓股判断当前估值状态：

| 股票 | 当前PE | 历史均值 | 估值状态 | 操作方向 |
|------|--------|---------|---------|---------|
| | | | 虚高/偏高/偏低/超跌 | 减仓/持有/加仓 |

估值四分类标准：
- 虚高：PE > 均值+1标准差
- 合理偏高：均值 < PE < 均值+1标准差
- 合理偏低：均值-1标准差 < PE < 均值
- 超跌：PE < 均值-1标准差

### 1.3 仓位平衡检查
- [ ] 各股票仓位占比是否在12%-20%区间？
- [ ] 是否有股票因大涨导致仓位被动超过25%？
- [ ] 预留现金是否≥10%？
- [ ] 组合整体是否需要再平衡？

---

## 二、下周操作规划

### 2.1 价格临界点预判
对每只关注的股票，预判下周可能到达的价格临界点：

| 股票 | 当前价 | 支撑位 | 压力位 | 到达支撑位操作 | 到达压力位操作 |
|------|--------|--------|--------|--------------|--------------|
| | | | | 买/卖/不动 | 买/卖/不动 |

### 2.2 建仓计划
如有计划新建仓的股票：
- [ ] 公司分析五步法是否完成？
- [ ] 三维评分是否≥3星？
- [ ] 风险折价是否计算？
- [ ] 当前估值状态是否适合建仓？
- [ ] 底仓比例（建议30%）？
- [ ] 分档加仓计划（支撑位各买多少）？

### 2.3 减仓计划
如有计划减仓的股票：
- [ ] 减仓理由是否符合买卖一致性原则？
- [ ] 减仓比例？
- [ ] 减仓后资金投向？

---

## 三、买卖一致性检查

对每只持仓股，回顾买入逻辑是否仍然成立：

| 股票 | 买入理由 | 当前是否仍成立 | 不成立则操作 |
|------|---------|--------------|------------|
| | | 是/否 | 持有/减仓/清仓 |

**买卖一致性原则：**
- 以什么理由买，就以什么理由卖
- 买入理由消失时，就是卖出时机
- 不因股价涨跌而改变买卖逻辑

---

## 四、红利股专项检查（如持有红利股）

- [ ] 股息率是否仍≥4.5%？
- [ ] 公司业绩是否稳定？
- [ ] 分红是否有可持续性？（经营现金流是否覆盖分红）
- [ ] 是否出现"低估值陷阱"（业绩下滑导致高股息）？
- [ ] 是否需要高切低操作（卖出股息率降到4%以下的，买入5%以上的）？
- [ ] 分红再投资计划？

---

## 五、学习与提升

- [ ] 本周是否有新的行业/公司研究？
- [ ] 是否更新了公司分析模板中的跟踪指标？
- [ ] 是否有需要补充学习的知识领域？
- [ ] 本周操作是否有违反纪律的地方？

---

## 六、下周纪律提醒

1. 盘中只执行周末制定的计划，不临时起意
2. 价格到达临界点时，按计划执行，不犹豫
3. 不因盘中情绪改变操作
4. 如遇突发重大事件，先评估再操作，不追涨杀跌
5. 每天收盘后简单记录，周末统一复盘
