## 一、核心投资哲学

### 1.1 股票投资长期收益三要素

**来源视频：《股票投资长期收益构成》**

股票投资的长期收益由三个因素构成：

| 收益来源 | 性质 | 说明 |
|---------|------|------|
| **企业内在价值增长** | 正和博弈 | 公司通过经营创造价值，业绩持续提升 |
| **公司分红** | 正和博弈 | 公司盈利能力提升后给股东的回报，不受二级市场股价影响 |
| **估值波动** | 零和博弈 | 市场情绪和资金博弈导致的股价变化，你赚的是别人亏的 |

**核心观点：**
- 新手误区：认为炒股就是低买高卖赚差价，把复杂问题简单化
- 价值是可以被创造的：比如水成本几分钱，酿成酒可以卖上百元，差价就是公司创造的价值
- 投资者主要赚前两个收益（内在价值增长+分红），投机者主要赚估值波动的钱

### 1.2 戴维斯双击与双杀

**戴维斯双击：**
- 业绩增长 + 估值提升 = 股价涨幅 = 业绩涨幅 × 估值涨幅
- 案例：净利润10亿→15亿（+50%），PE 15→30（+100%），市值150亿→450亿（+200%）

**戴维斯双杀：**
- 业绩下跌 + 估值下跌 = 股价跌幅 = 业绩跌幅 × 估值跌幅
- 案例：万科2021年市值3000多亿→现在300多亿，跌去90%

**估值透支陷阱：**
- 业绩增长但估值下跌幅度更大，股价仍会长期下跌
- 案例：爱尔眼科PE从140倍跌到25倍（-82%），业绩只增长50%，市值跌75%
- 案例：海光信息PE 236倍，年利润27亿，业绩增长40%也难以消化高估值

### 1.3 价值投机理念

- 先吃透内在价值增长和分红的收益（长期年化10%-15%）
- 在这个基础上，再承担一定风险去赚估值波动的钱
- 就算投机失误短期被套，还可以通过长期持有实现稳定盈利
- 预期收益率会降低，但有保底

## 二、公司分析框架

### 2.1 公司分析五步法

**来源视频：《意华股份业务分析思维导图》**

| 步骤 | 分析内容 | 关键指标 |
|------|---------|---------|
| **第一步：公司概况** | 主业结构、营收规模、利润增速、ROE、毛利率、净利率 | 营收、净利润、ROE、毛利率、净利率、经营现金流 |
| **第二步：产品分析** | 产品矩阵（核心层/战略层/辅助层/淘汰层）、竞争力、壁垒、客户 | 产品分层、技术壁垒、客户绑定、定价权 |
| **第三步：营销分析** | 销售模式、客户结构、营销效率、毛利率变化 | 直销/分销、客户集中度、毛利率、利润增速 |
| **第四步：制造分析** | 制造模式、成本结构、产能布局、制造效率 | 自主制造/外包、总资产周转率、固定资产占比 |
| **第五步：综合评估** | 三维评分 + 风险折价 + 跟踪指标 | 产品/营销/制造评分、风险折价比例 |

### 2.2 产品矩阵四层模型

| 层级 | 定位 | 说明 |
|------|------|------|
| **核心层** | 基本盘和利润主力 | 稳定贡献收入和利润的产品 |
| **战略层** | 未来增长极 | 高增速、新赛道的突破口 |
| **辅助层** | 稳定补充 | 贡献收入但不是重点 |
| **淘汰层** | 逐步收缩 | 落后产品，正在退出 |

### 2.3 三维评分体系

| 维度 | 评分标准 | 意华股份案例 |
|------|---------|-------------|
| **产品竞争力** | 技术壁垒、客户绑定、定价权 | ★★★★（4星） |
| **营销效率** | 销售模式、客户结构、毛利率 | ★★★（3星） |
| **制造效率** | 自主制造、成本优势、产能利用率 | ★★★★（4星） |

### 2.4 风险折价模型

对识别出的风险给予估值折价：

| 风险类型 | 折价比例 | 说明 |
|---------|---------|------|
| 大客户依赖 | 10%-15% | 单一客户收入占比过高 |
| 地缘政治/关税 | 10%-15% | 贸易壁垒、关税风险 |
| 行业竞争加剧 | 5%-8% | 竞争对手抢份额 |
| 周期性需求 | 5%-8% | 需求有周期性波动 |
| 汇率风险 | 5%-8% | 海外收入占比高 |

**意华股份案例：** 综合风险折价30%-40%

### 2.5 关键跟踪指标

每个公司分析后必须列出7个左右的跟踪指标，持续监控：
- 核心业务收入增速
- 大客户收入占比变化
- 订单量/排产情况
- 毛利率变化趋势
- 经营现金流/净利润比值
- 新产能利用率
- 汇兑损失/非经常性损益

## 三、交易体系

### 3.1 买卖一致性原则

**来源视频：《从入门到精通，股票投资学习路径》**

> 以什么理由买，就以什么理由卖。

**案例：农业银行**
- 买入逻辑：估值低、分红高、成长性弱也可接受
- 持有过程：股价从2块多涨到7块多，业绩没增长
- 卖出逻辑：估值变高、分红率变低，超过心理临界值
- 结论：止盈，因为买入理由（低估值高分红）已经不存在

**核心要点：**
- 从买入到卖出始终看同一组指标
- 不因为股价涨跌而改变买卖逻辑
- 止盈止损基于基本面和估值，不基于价格波动

### 3.2 建仓策略

**来源视频：《投资组合的仓位管理思路》**

1. **不一次性满仓**：建仓周期长达1-2年
2. **分批建仓**：根据支撑位和压力位区间，层层狙击
3. **底仓先行**：先买计划仓位的30%作为底仓
4. **越跌越买**：跌到支撑位加仓，每档买入比例递减
5. **基本面驱动调整**：业绩上涨→加大买入节奏，业绩恶化→减仓

### 3.3 动态调仓

- 估值高的减仓，估值低的加仓
- 保持组合内各股票仓位平衡
- 重仓股通常是"涨出来的"，不是"补仓补出来的"
- 股价大涨导致仓位被动提高时，适度减仓恢复平衡
- 减仓踏空只是少赚，套牢才是真亏

### 3.4 周末复盘制

**核心原则：凡事预则立，不预则废，禁止盘中临场决策**

周末复盘清单：
1. 审视所有持仓股的基本面变化
2. 预判下周各股票价格可能到达的临界点
3. 提前规划：到什么价格、买/卖多少、仓位是否失衡
4. 盘中只执行周末制定的计划，不临时起意

## 四、仓位与风险管理

### 4.1 投资组合原则

**来源视频：《投资组合的仓位管理思路》**

| 原则 | 具体要求 |
|------|---------|
| **组合数量** | 5-8只股票（低于5只对冲不足，超过8只精力不够） |
| **单票仓位** | 每只分配总资金的12%-20% |
| **预留现金** | 总资金的10%预留应对波动 |
| **不满仓** | 永远保留应对极端情况的资金 |

**为什么要组合投资：**
- 投资有风险，再厉害也会看走眼
- 单吊一只遇到黑天鹅可能是永久性损失
- 8只中错1只，其他7只正常增长，组合仍稳定盈利
- 前提：大部分公司判断正确（基本功扎实）

### 4.2 风险偏好匹配

**自测问题：你更怕踏空还是更怕账户浮亏？**

| 风险偏好 | 建仓时机 | 适合的股票类型 |
|---------|---------|--------------|
| **极度厌恶风险** | 等估值超跌（大熊市才出现） | 业务稳定、高分红 |
| **风险中立** | 估值合理偏低时建仓 | 稳健成长型 |
| **风险偏好高** | 估值合理即可，看重K线趋势 | 高成长、高波动 |

**匹配原则：**
- 持股必须与风险偏好匹配，否则持股过程很折磨
- 风险低的人买高波动股，容易在低位割肉
- 风险高的人买稳定股，会觉得无聊而清仓

### 4.3 估值四分类

用PE历史均值±1个标准差划分：

| 估值状态 | 判断标准 | 操作策略 |
|---------|---------|---------|
| **估值虚高** | PE > 均值+1标准差 | 不买，持有则减仓 |
| **合理偏高** | 均值 < PE < 均值+1标准差 | 谨慎，不新开仓 |
| **合理偏低** | 均值-1标准差 < PE < 均值 | 风险中立者可建仓 |
| **估值超跌** | PE < 均值-1标准差 | 极度厌恶风险者建仓时机 |

### 4.4 技术分析辅助

- 价值分析为主，技术分析为辅
- 前者判断大方向，后者找操作机会
- 划定支撑位和压力位，形成股价操作区间
- 在区间低位买入，区间高位适当卖出
- 跌破最低支撑位通常意味着基本面出了问题

### 4.5 破位处理

- 股价跌破最低支撑位，通常是基本面发生重大问题
- 不是仓位管理失效，而是前面的业务/估值分析失误
- 承认损失，做好复盘
- 判断是否继续持有：不持有则清仓，持有则等新区间形成后再操作

## 五、红利股投资策略

### 5.1 红利股核心逻辑

**来源视频：《红利股投资需关注的核心考量与风险分析》**

- 以分红为核心目标，追求被动现金流持续增长
- 适合低风险偏好投资者
- 长期持有，通过分红收回成本

### 5.2 红利股筛选标准

| 标准 | 要求 | 说明 |
|------|------|------|
| **股息率** | ≥4.5%-5% | 低于5%的银行股不用看 |
| **业务稳定性** | 业务稳定、不需要大额资本再投入 | 赚的钱可以全部分给股东 |
| **分红持续性** | 分红有持续盈利能力支撑 | 不是掏空家底的一次性分红 |
| **估值合理性** | 价格便宜时买入 | 股价涨高后股息率下降，不划算 |

### 5.3 红利股陷阱识别

**陷阱1：低估值陷阱（格力电器）**
- 表面：股息率7.3%很高
- 实质：业绩8年零增长，受房地产拖累
- 风险：现金覆盖不了短期债务，分红不可持续
- 结论：产品型公司业绩零增长是失败的

**陷阱2：周期股伪装（中远海控）**
- 表面：股息率10%
- 实质：疫情期间赚了两年快钱，是周期性公司
- 风险：逆全球化+新船运力投放，利润可能大幅下滑
- 结论：周期股不是红利股，风险与低风险偏好不匹配

**陷阱3：掏空家底分红（东方雨虹）**
- 表面：股息率13%惊人
- 实质：公司已亏损，分红44亿是掏空家底
- 风险：老板可能想把钱掏出来搞别的生意
- 结论：高分红没有持续性

### 5.4 红利增长四方法

每年分红目标增长20%的实现路径：
1. **公司业绩增长** → 分红自然上涨
2. **红利再投资** → 分红收到后再买股票，增加持股数
3. **高切低操作** → 卖出股息率降到4%的，买入股息率5%的
4. **追加投资** → 劳务收入继续投入优质资产

## 六、投资者能力分级

**来源视频：《股票投资者能力分级与知识地图》**

### 6.1 四级能力模型

| 级别 | 核心标志 | 能力要求 | 典型人群 |
|------|---------|---------|---------|
| **未入门** | 不知道买股票=买公司 | 看不懂企业运作，只看K线预测涨跌 | 教师、学生、公务员等 |
| **初级** | 认知到买股票=买公司 | 了解基础财务指标（业绩、利润、增长率） | 企业白领、上市公司员工 |
| **中级** | 具备企业估值能力 | 能解读财务三表，理解财务数据背后的业务场景 | 公司管理层、大厂骨干 |
| **高级** | 重视商业模式 | 战略管理+风险管理+宏观分析能力 | 企业家、合伙人 |

### 6.2 知识地图六大维度

| 维度 | 初级 | 中级 | 高级 |
|------|------|------|------|
| **财务知识** | 基础财务指标 | 财务三表解读（中级会计） | CPA级别会计 |
| **公司运营** | 了解企业运作 | 财务管理流程 | 公司战略与风险管理（CPA） |
| **金融知识** | 投资品种、PE/PB | 估值方法（DCF等） | 金融衍生品、量化 |
| **经济学** | 基础概念 | 宏观经济指标 | 宏观经济周期、地缘政治 |
| **信息处理** | Excel基础 | 数据分析 | 量化交易、AI应用 |
| **软技能** | 心态管理 | 行为经济学 | 克服人性弱点 |

### 6.3 核心观点

- 入门分界线是**认知**（买股票=买公司），不是技能
- 初级→中级分界线是**估值能力**（硬技能）
- 中级→高级分界线是**对商业模式的重视程度**（认知升级）
- 不需要成为六边形战士，知道短板在哪里慢慢提升即可
- 可以通过合作扬长避短

## 七、学习路径（18章课程体系）

**来源视频：《从入门到精通，股票投资学习路径》**

### 初级（第1-5章）
1. 为什么要学习投资（现金流为王，不是现金为王）
2. 股票和交易所的起源（风险共担、收益共享）
3. 投资品种分类（固收/股权/债券/货币/商品/衍生品）
4. 现代企业如何运作
5. 公司基础财务指标（盈利/偿债/运营效率三类）

### 中级（第6-12章）
6. 从初创到IPO的全过程
7. 公司财务管理（财务三表如何产生）
8. 财务三表解读（重点看资产负债表）
9. 估值方法（PE/PB相对估值 + DCF现金流折现）
10. K线技术分析（报价系统，非企业真实价值）
11. 交易方法（建仓1-2年、动态调仓、买卖一致性）
12. 宏观经济指标（GDP/通胀/PMI/行业数据）

### 高级（第13-18章）
13. 信息技术在投资中的应用（Excel/数据库/量化/AI）
14. 行为经济学（有限注意力、厌恶损失）
15. 公司战略管理与风险管理
16. 金融衍生品（期货/期权/可转债，不建议个人使用）
17. 地缘政治对经济的影响
18. 宏观经济学（经济周期：人口周期/政治周期）

## 八、与现有量化系统的融合点

| 现有模块 | 黄阳体系融合方向 |
|---------|----------------|
| **基本面过滤** | 从PE/ROE硬指标 → 升级为三维评分（产品/营销/制造）+ 风险折价模型 |
| **选股逻辑** | 从纯技术突破 → 增加"价值成长策略"：低估值+高分红+业绩稳定增长 |
| **仓位管理** | 从固定比例 → 升级为动态估值平衡调仓（高切低） |
| **买卖规则** | 从固定止盈止损 → 升级为买卖一致性原则驱动 |
| **复盘机制** | 从每日推送 → 增加周末深度复盘（持仓检视+下周规划） |
| **红利股策略** | 新增独立策略：股息率≥5%+业务稳定+分红可持续 |
| **风险控制** | 增加估值四分类，估值虚高时自动减仓 |
