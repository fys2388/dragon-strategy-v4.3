## 一、为什么要学习财务知识

**投资赚钱靠行情是靠不住的。行情有好就有坏，行情好的时候躺着就能赚钱（买啥大概率都涨），但行情不会一直好。当市场开始单边下跌时，如果没有知识储备、对公司经营状况不了解、对二级市场规律不熟悉，就只能两眼一黑听天由命。**

- 越是在市场充满风险的时候，越应该意识到知识的重要性，沉下心来好好学习
- 用自身的商业分析能力来对抗二级市场的不确定性
- 成年人看书应该带着学习目标去看，读书推荐最好和投资课程搭配在一起学习
- 投资课程作用：帮我们把投资知识框架搭建起来，知道做投资的正确步骤和方法
- 但只知道步骤和方法论没用，要把事情干成还需要相应知识储备
- 看书目标：在知识框架搭建好的情况下尽快把知识点补全

### 财务能力的定位
- **财务能力是取得投资成功的必要非充分条件**
- 对于公司经营者来说，老板和高管基本上都是懂财务的
- 财务基础知识类似于高级一点的乘法口诀表，内容其实不多，多花点时间一定可以啃下来
- 基础知识并不难学，甚至可以使劲背下来，等到以后用财务知识分析商业模式时，用的次数多了慢慢就会融会贯通

### 关于"财务太难学不会"
- 都说学不会，那说明没这个能力吃这碗饭
- 股票投资本来就是比较难的东西，这种能力掌握之后加上一定资本，最后大概率可以实现财务自由，这种级别的能力怎么可能随随便便掌握？
- 要是真这么简单，岂不是人人都躺在床上赚钱了？这种明显和现实不符的事情一定要好好思考
- **难学就对了，难才证明这个东西的价值**
- 不过也不用气馁，这个东西又不是升学考试，并不是说非要在一个时间限制内学会，短期学不会可以慢慢学，一直学到学会为止
- 毕竟是掌握之后就能够轻松在家躺平的手艺，是值得花费大量时间和精力来学习的

## 二、五本书推荐（有先后顺序）

学习路径：先入门了解什么是财务建立财务知识框架→基础打好后告诉知识怎么用于公司业务分析→如何用于判断上市公司经营质量→如何利用财务数据给公司估值

### 第1本：CPA会计（或中级会计实务）

**目标：先把财务基础概念了解一下，理解什么是做账、什么是科目、什么是凭证、什么是财务三张表。**

- 如果觉得CPA难度比较大，可以降低难度买本中级会计实务
- 十年前肯定会说这些基础知识只能通过看书学习，但现在信息化发达有更高效的学习方式
- **实践为主+搭配看书效果更好**：
  - 企业软件流行SaaS版本，可以直接买一个企业用的财务管理系统（SaaS版本不贵，一年大概几百块钱），自己学着做一套账，把常见业务凭证写一写，试着生成财务三张表
  - 在公司上班的朋友可以自己模拟做一下公司的账，然后找财务部同事指导一下
  - 没有条件就拿自己家里日常收支来做账，把日常生活开支都按照会计标准来做账，一样能起到不错效果
  - 遇到凭证不会写的、名词解释不太懂的，再去翻一下书就行了
- 这个方法绝对好用，对于天赋比较高的人来说个把月基本上就上手了
- 学习财务知识并不是为了去企业做财务工作，而是要学会如何解读财报，做到这点比能做账要简单一些，还是很容易入门的

### 第2本：肖星《一本书读懂财报》

**目标：把财务基础知识夯实，建立财务宏观框架。**

- 肖星老师被誉为清华会计学第一老师，非常擅长用通俗易懂的比喻讲透复杂财务概念
- 只有把一件事情的本质理解得特别透彻，才能用通俗易懂的方式把知识讲解出来
- 这本书最大亮点不是教你记科目（科目知识在之前学习环节就应该掌握了），核心内容是更加侧重于深入剖析财务三张表的内在逻辑联系
- 可以帮我们建立起财务的宏观框架
- 比较适合逻辑思维强、希望从原理上彻底搞懂财报体系的初学者
- 读完之后会对财报有一个整体稳固的认知，不容易忘记
- 比较适合财务新手小白作为入门阅读
- 如果是财务专业的朋友可以跳过这本书，因为还是以打基础为主

### 第3本：刘顺仁《财报就像一本故事书》

**目标：开始教如何应用财务数据去分析公司业务。**

- 肖星老师的书是在帮我们打基础，刘顺仁这本书开始教如何应用财务数据去分析公司业务
- 不仅讲财务数据，更着重分析财务数据背后的公司管理决策
- 探讨CEO如何通过财报传达经营理念，投资人如何通过财报看穿管理层的虚实
- 大量运用财务分析案例，教我们从财务数据中去解读企业的战略
- 适合对商业故事感兴趣、希望能快速上手分析实战的读者
- 读起来趣味性更强一些，读完之后应该立刻能激发起使用财报来分析公司的兴趣

### 第4本：唐朝《手把手教你读财报》

**目标：投资人是如何解读财报的，会计科目深度解读和造假识别。**

- 前两本书是大学老师写的，偏学术一些，重点是公司业务领域的分析
- 唐朝本身是比较有名的价值投资者，并非学院派或者金融科班出身，知识体系都来源于投资实践
- 学术严谨度会略微低一点，但投资的实践性拉满了
- 甚至可以直接打开一个上市公司的财报，然后拿这本书一步步去分析，确实可以做到手把手教你怎么看财报
- 更侧重于会计科目的深度解读和造假识别
- 适合本身就已经有一定财务基础、用财务能力去股市实战的投资者

### 第5本：弗里克曼《公司估值》

**目标：如何用公司财务数据来计算公司的内在价值。**

- 作为投资者学习财务并不是为了去公司上班当财务，而是为了三个目的：
  1. 通过财务数据来验证公司的商业模式
  2. 判断公司的经营质量
  3. 通过财务数据计算公司的内在价值
- 前面几本书的作用是前两个目的，最后一本书就是教第三个目的
- 可以教如何搭建估值模型，从历史财报的分析到预测未来的三表，再到最终的自由现金流折现，每一步都在引导给出理由和假设
- 在给公司估值的过程中会带我们思考：这家公司的护城河是什么？它的增长是创造价值吗？公司的经营风险有哪些？
- 这本书有阅读门槛，放在第五本推荐是因为如果没有前面四本书的基础作为铺垫，这本书可能比较难以读下去

## 三、五本书的金字塔结构关系

下层是打基础的，上层是投资应用，上层的能力是否能顺利使用取决于下层基础有多牢固。

```
        ┌─────────────────┐
        │ 5. 公司估值      │ ← 弗里克曼《公司估值》
        │  （内在价值计算） │
        ├─────────────────┤
        │ 4. 投资实战      │ ← 唐朝《手把手教你读财报》
        │  （科目解读+造假识别）│
        ├─────────────────┤
        │ 3. 业务分析      │ ← 刘顺仁《财报就像一本故事书》
        │  （财务→公司战略）  │
        ├─────────────────┤
        │ 2. 财务框架      │ ← 肖星《一本书读懂财报》
        │  （三张表内在逻辑） │
        ├─────────────────┤
        │ 1. 基础概念      │ ← CPA会计/中级会计实务
        │  （做账/科目/凭证） │
        └─────────────────┘
```

### 阅读顺序

1. **第一步**：先看会计实务或者买一套SaaS版财务系统，自己上手摸索，对财务会计工作有初步认识，把基础概念熟悉一遍（知道什么是做账、科目、凭证、财务三张表）
2. **第二步**：跟着肖星学框架，看《一本书读懂财报》，帮助建立清晰的财务世界观，知道整个游戏规则是怎么建立的。如果没有这个框架，后面学的所有技巧都是很零散的，这本书是基本功
3. **第三步**：跟着刘顺仁学习分析，看《财报就像一本故事书》。有了框架之后通过这本书看财报分析，帮助把财务语言翻译成公司的业务，提供使用财务数据分析业务的能力启蒙
4. **第四步**：跟唐朝学习投资实战，看《手把手教你读财报》。当真的拿钱出来投资股票的时候，这本书就是财务分析的操作手册，内容非常务实，能够带我们一点点检查财报，排除掉垃圾公司，选出真正优秀的公司
5. **第五步**：向弗里克曼学习公司估值。使用公司财务数据去计算公司的内在价值，当掌握这个能力之后股票交易就有了自己的节奏，就不会被二级市场的混乱报价所影响了

## 四、关键结论

1. 投资赚钱靠行情靠不住，行情不好时需要知识储备对抗不确定性
2. 财务能力是投资成功的必要非充分条件，像高级乘法口诀表，内容不多可以啃下来
3. 难学才证明价值，掌握后大概率能实现财务自由，值得花大量时间精力学习
4. 五本书按金字塔顺序阅读：基础概念→财务框架→业务分析→投资实战→公司估值
5. 学习财务可以用实践方式：买SaaS财务系统自己做账，或拿家庭日常收支按会计标准做账，遇到不懂再翻书
6. 肖星《一本书读懂财报》建立财务宏观框架，是基本功
7. 刘顺仁《财报就像一本故事书》把财务语言翻译成公司业务，趣味性强
8. 唐朝《手把手教你读财报》是投资实战操作手册，侧重科目解读和造假识别
9. 弗里克曼《公司估值》教搭建估值模型和自由现金流折现，有阅读门槛需前面四本基础
10. 掌握估值能力后股票交易就有了自己的节奏，不会被二级市场混乱报价影响
