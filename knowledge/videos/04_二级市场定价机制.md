## 一、二级市场的本质

**定义：** 二级市场 = 二手市场（二手货的意思）
- 交易的是其他投资者的二手股权，不是向上市公司直接购买
- 类比：专门买卖公司股权的闲鱼二手交易平台
- A股只有4500多个商品，质量标准化很高

**核心特征：** 商品质量需要自己评估，价格由卖家自由报价，成交价取决于供需关系。

## 二、股价如何被决定

### 2.1 IPO阶段定价

| 环节 | 说明 |
|------|------|
| 路演 | 管理层向投资者讲解业务、增长潜力、融资规划（营销性质） |
| 询价 | 投资人根据自己判断报价 |
| 最终定价 | 发行人+承销商综合报价、市场环境、大盘走势、融资目标敲定 |
| 认购 | 一手交易，资金直接进入上市公司 |

### 2.2 日常交易定价：少数交易者决定价格

**二手房案例：**
- 小区1000套房，990套业主自住不挂牌
- 只有10套挂牌交易，这10套的成交价决定整个小区房价
- 大多数业主不参与交易，对房价影响极低

**股票市场同理：**
- 大部分股票被持有不交易
- 只有少数流通股参与定价
- 这解释了为什么新股容易被炒出天价、妖股可以被操控

### 2.3 新股炒作机制

**案例：影石创新**
- IPO前股本3.6亿股，发行4100万新股（占10.22%）
- 无禁售限制的股份仅3000多万股（占总股本7.61%）
- 发行价47.27元（20倍PE，偏低）
- 全部流通股只需14.18亿就能买完
- 持有者心照不宣锁死流动性 → 买家持续加价 → 开盘直接拉到180元

**关键数字：**
- 总股本<4亿：发行量不得低于25%
- 总股本>4亿：发行量放宽到10%
- 很多公司IPO前把股本调到3.6亿，刚好卡规则只发行10%

**实践建议：** 只考虑上市超过3年的公司（全部解禁，流通盘大，不易被人为影响）。

### 2.4 妖股操控机制

1. 操盘手与大股东合作，锁死大量股份流动性
2. 妖股初始市值通常仅20-30亿，持股集中
3. 用少量资金拉抬少量流通股价格
4. 股价上涨产生造富效应，吸引贪婪散户
5. 管理层配合发布利好
6. 高价出货，完成韭菜收割

## 三、市场有效性分析

### 3.1 A股定价效率不高的证据

**AH股价差案例（中信国际，2025年6月13日）：**
- 科创板：82元/股
- 港交所：40港元/股 = 36.4元人民币
- 价差128%，肯定有一个定价错误

### 3.2 信息传播效率问题

**亲身经历案例（2014年地产公司资产重组）：**
- 公司总部普通员工年底都在讨论合并事宜
- 但股价当时没有大变化
- 半年后"消息灵通人士"才来推荐，股价已从10元涨到30元
- 结论：听到的消息大概率是传了半年的N手消息

**高管也不可靠：**
- 高管最多提前知道本财年业绩
- 对未来发展趋势自己也不清楚
- 企业战略每年底制定，只管一年，还经常误判
- 案例：上海某上市房企CFO拍胸脯说"稳得很"，一年后财务爆雷退市

### 3.3 市场过度反应

**原因：** A股参与人数基数大，极端情绪人群数量多
- 股价最高点 = 情绪盲目乐观且冲动的人买出来的
- 股价最低点 = 情绪最悲观的人割肉割出来的
- 极端情绪的人交易频率远高于理智投资者

### 3.4 基金导致的泥沙俱下

- 行情不好时，基金持有者因恐惧赎回基金
- 基金经理被迫卖出持仓（包括优质公司）
- 导致优质公司股价和普通公司一起暴跌
- 老练投资者利用这种局面抄底

### 3.5 短视频放大情绪

- 2024年10月股市大涨一周，短视频平台铺天盖地推送
- 算法形成信息茧房，情绪不断放大
- 十一后第一个交易日大盘高开夸张点位，随后持续回调
- 8个月后指数仍未恢复当时最高点
- 结论：现在股市极端情绪比以前更极端，超涨超跌更多

## 四、K线技术分析的定位

### 4.1 总体看法

- K线分析作用非常有限，不打算单独讲
- K线基于二级市场报价分析，而报价大多数时候不合理
- 在错误信息上分析很难得到有价值结论
- 类比：放着商品质量不研究，天天盯着价格波动研究

### 4.2 两个有用的理论

**1. 美人投票理论（凯恩斯）**
- 通过K线揣摩其他投资者想法，提前布局
- 必须在搞清楚公司业务的前提下使用
- 在垃圾公司上搞技术分析 = 在稿纸上雕花

**2. 预期自我实现**
- 市场普遍预期通过自身行为影响价格，最终使预期成真
- 支撑位/压力位：很多投资者相信，到位置就操作，导致真的有效
- 即使基本面恶化，股价也会暂时在支撑位止跌

### 4.3 学习建议

- 技术分析是后期学习内容，锦上添花
- 新手提前学容易被误导（实操性强，马上有正反馈，忽略真正重要的东西）
- 推荐书：马丁·J·普林格《技术分析》，看这一本就够

## 五、市场先生理论（格雷厄姆）

**核心比喻：** 市场是一个情绪不稳定的生意伙伴
- 每天向你报价，想买你的股份或卖给你他的股份
- 有时极度乐观，想高价收购
- 有时极度悲观，低价抛售甚至恐慌甩卖

**正确做法：**
- 不被市场先生影响，决策基于企业真实价值
- 反向利用市场先生的不理智
- 市场悲观时低价买入优质资产
- 市场狂热时高价卖出股票

**日常应用：**
- 把二级市场报价当成每天更新的报价单
- 心中有企业价值标准（业务分析+财务分析+估值分析）
- 报价合适 → 考虑交易
- 报价不合适 → 不管它，一直等满意价格

## 六、财报期与非财报期

| 时期 | 股价驱动因素 |
|------|------------|
| 非财报期 | 市场情绪、资金偏好 |
| 财报期（4/30、8/31、10/31） | 股价向基本面靠拢 |

**遛狗理论：** 股价和内在价值像牵狗绳遛狗，狗一会前一会后，但总会回到主人身边。

**经验观察：** 市场大部分时间，大部分公司股价都不合适（要么贵了，要么便宜），合适的反而少。

**数据验证：** 把所有上市公司市值走势和业绩走势叠加，时间足够长，市值一定跟着业绩走，5000多家无一例外。
