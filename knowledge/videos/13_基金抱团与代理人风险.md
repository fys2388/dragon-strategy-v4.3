## 二、代理人风险机制

### 2.1 定义

当委托人和代理人利益不一致，且信息不对称时，代理人会为追求自身利益损害委托人利益。

**基金是代理人风险高发区：**

| 角色 | 目标 |
|------|------|
| 投资者（委托人） | 赚钱 |
| 基金经理（代理人） | 扩大基金规模，收更多手续费 |

### 2.2 为什么必须抱团

- 基金经理必须极限追求收益
- 市场出现主线机会必须追，不追就净值落后同行
- 净值落后 → 客户赎回 → 基金可能清盘 → 奖金没了+被贴"菜狗"标签
- 可能活不到风险爆发的时候

**张坤案例：**
- 巅峰期管理规模1345亿 → 被赎回到31亿（零头都不到）
- 因不抱团、死守消费股 → 6月被架空，加入新基金经理共同管理
- 换人后：消费割肉在地板上，加仓科技股又跌一整月，两头挨打

### 2.3 绩效考核改革无效

- 2023年基金行业改绩效设计：3年以上业绩低于基准扣钱、风格漂移扣钱
- 结果：一点用没有，该抱团还是抱团，且比2021年更过分
- 原因：扣钱是两三年后的事，不抱团今年工作都可能丢

## 三、估值泡沫循环

```
AI技术突破 → 增量订单 → 股价合理上涨
→ 趋势交易者（基金）抢筹 → 供需失衡 → 股价超内在价值
→ 基金净值上涨 → 基民追加投资 → 更多资金买入
→ 股价进一步上涨 → 强化投资信心
→ 一直涨到全民一致看多（最危险）
```

**见顶信号：**
- 外面没有新的增量资金
- 所有口头多头实际都是空头（没钱买了，只能卖）
- KTV小妹都在买光模块和存储龙头

## 四、历史对比与"一鱼两吃"

**2021年白马股抱团崩溃路径：**
1. 2021年初暴跌一轮
2. 大多数公司又拉回去
3. 2021年5月拉回前期高点但突破不了
4. 没有接盘的人 → 看谁跑得快
5. "一鱼两吃"：下跌周期中很多人因抢反弹再次高位买入，被收割两次

**2026年AI抱团现状：**
- 7月资金抱团松动，不少公司直接腰斩
- 上杠杆的人爆仓
- 第一次下跌企稳时很多人不割肉，反向加仓
- 财报期观望，等业绩看是否再炒一轮

## 五、寒武纪案例

- 2026年Q2业绩30亿，同比增长大但环比已慢
- 市值7500亿，对应单季度30亿业绩
- 科创板门槛50万，一手200股，买一手需24万
- 基金持有占比13%，个人账户持有不到10%
- 基金接盘：泡沫破了亏基民的钱，基金经理顶多扣奖金，搞对了扬名立万

## 六、海天味业案例（抱团后遗症）

- 2021年初市值7000亿高位 → 现在2000亿（还可能继续跌）
- 业绩一直不错，资产结构漂亮，但股价跌了5年半
- 21年最高点买入 → 套10年都回不了本
- 食品板块龙头尚且如此，垃圾公司可能直接告别股市

## 七、关键结论

1. 基金抱团是代理人风险的必然结果，不是偶然
2. 基民选基金只看谁涨得好，进一步强化抱团
3. 绩效考核改革无法解决根本问题（生存压力 > 长期考核）
4. 全民一致看多是见顶信号
5. 抱团崩溃后会有"一鱼两吃"（抢反弹被二次收割）
6. 这是第二次基金抱团，历史经验应吸取
7. 基金经理亏的是基民的钱，自己顶多扣奖金
