## 四、中级篇-二级市场（第13-19章）

| 章节 | 内容 |
|------|------|
| 第13章 | 如何对公司进行估值。前面6-12章是估值分析的输入，根据经营情况判断内在价值。新手股价犯迷糊=缺估值分析环节，没有内在价值参考 |
| 第14章 | 股票市场定价机制。股价=所有投资者共识，不代表真实价值。市场经常给垃圾公司贵价格、给优质公司便宜价格。不要套用商品定价思路（贵的一定好） |
| 第15章 | 投资和投机的区别：追求内在价值增长vs追求价格上涨。股市是赌场还是投资平台取决于自己的认知和选择 |
| 第16章 | 投资哪种类型公司取决于投资目标和风险偏好。成长型公司（业绩快但盈利不稳定）vs成熟大型公司（增长慢但盈利稳定） |
| 第17章 | 选股思路和方法（A股5400家公司不可能每家都看） |
| 第18章 | 投资组合和长期配置。可以同时投资很多家公司，规避满仓躲牛市，东边不亮西边亮。不同行业股价波动相互对冲，账户波动平稳降低焦虑 |
| 第19章 | A股指数体系，为什么编制指数，如何指导投资操作 |

## 六、关键结论

1. 投资对普通人是必选项，持有现金=被通货膨胀吃掉财富
2. 课程核心逻辑：先理解公司经营（6-12章），再做估值（13章），再理解市场定价（14章），最后区分投资和投机（15章）
3. 新手股价犯迷糊的根本原因是没有估值分析，没有内在价值作为参考
4. 投资组合可以规避满仓风险，不同行业波动相互对冲，降低焦虑
5. 高级篇核心：行为经济学解决心态，信息技术解决技术，宏观经济周期解决时机
6. 宏观分析目标：经济转暖时下重仓，经济衰退前提前减仓
