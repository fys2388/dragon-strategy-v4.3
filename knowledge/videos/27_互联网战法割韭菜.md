## 一、互联网战法套路

**操作流程：**
1. 游资和大V提前埋伏基本面很差的垃圾股
2. 利用网络影响力疯狂造势、刷曝光，把股票炒热
3. 吸引大量散户跟风追涨，帮他们抬轿子
4. 股价拉到高位后，把筹码甩给散户，完成收割

**演变：**
- 以前：借势炒作，依赖外部事件驱动
- 现在：直接让流量大V带节奏，不用搞热点布局，用大V流量强行提高股票关注度
- 2024年有个财经网红喊票被全网封杀，开了坏头

## 二、有限注意力偏差（核心原理）

### 2.1 定义

人的大脑一次只能聚焦少数关键信息，自动忽略无关内容。

### 2.2 进化起源

- 远古时期生存环境恶劣，危险无处不在
- 草丛一动/听到异响 → 注意力瞬间锁定异常点，屏蔽其他所有信息
- 快速判断是猎物还是危险（可能是老虎）
- 没有这种机制 → 大脑同时处理海量信息 → 反应迟钝 → 被老虎吃掉
- 进化论适者生存筛选出来的生理机制

### 2.3 基因与环境错配

- 生理机制是成千上万年进化出来的
- 现代社会生活方式才几百年
- 本能生理机制不适应现代生活
- 典型案例：开车看手机危险、看电视入神听不到老婆说话

## 三、股市中的注意力驱动溢价

### 3.1 经典案例

| 事件 | 被炒作股票 | 原因 |
|------|-----------|------|
| 中东打仗封锁海峡，油价大涨 | 金龙鱼 | "油"字关联，食用油≠石油 |
| 川普竞选领先 | 川大智胜 | 谐音"川大制胜" |
| 拜登选票追上来 | 乔治白 | 拜登=乔治·拜登 |
| 奥巴马竞选总统 | 奥马电器 | 谐音 |

### 3.2 机制

1. 外部事件发生 → 新闻满屏都是关键词
2. 散户没有深度研究公司能力，大脑优先处理简单显眼信息（谐音梗、关键词）
3. 有关联的股票关注度瞬间提高
4. 冷门小公司，关注人数基数大 → 一定比例的人会想买
5. 供需失衡，买盘多于卖盘 → 股价上涨
6. 股价上涨 → 注意力进一步聚焦到股价变化 → 忽略基本面
7. 大家抢着买，挂高价 → 股价一路顶上去
8. **金融学称之为：注意力驱动的溢价**

## 四、产业链运作

**光伏公司案例：**
- 公司预告：光伏行业结构性产能过剩，供需矛盾突出，组件价格低，营收减少，盈利能力下降
- 财务状况非常差，继续恶化可能退市
- 但股价还能涨 → 明显是人为造势
- 几个流量号在网上带节奏，提高曝光量
- 流量大V暗示自己已经买了 → 引来追涨的韭菜

**流量大V的角色：**
- 每天晒持仓的流量型大V
- 作品甚至不用推荐股票，背后产业链给作品投流
- 明明没关注，每天还是能刷到他们
- 负责提高股票曝光量就行了

**利益逻辑：**
- 凡是不合理却长期存在的事，背后一定有看不见的利益逻辑
- 这些人一年亏损几百万，但从来不反思投资方法
- 买来买去永远买那些涨到高位的垃圾股

## 五、为什么不能跟着游资走

1. **赚的是谁的钱？** 游资在垃圾公司上拉高出货，赚的不是公司经营成长的钱，必然是散户亏掉的钱
2. **与虎谋皮：** 散户往机构操作的股票上凑，就是典型的与虎谋皮
3. **"早信早进"的误区：** 明知道是庞氏骗局，早期参与能不能赚钱？
   - 见好就收非常困难，尝到甜头账户浮盈后不想走
   - 贪婪会让你选择留下来
   - 就算这次运气好跑掉了，能保证每次都运气好吗？
   - 股票亏损按百分比计算，被套一次大概率一夜回到解放前

## 六、关键结论

1. 有限注意力偏差是远古进化出来的生理机制，不适应现代股市
2. 外部事件→关键词关联→关注度提高→供需失衡→股价上涨=注意力驱动溢价
3. 游资+大V利用这个原理，人为制造曝光量吸引散户接盘
4. 金龙鱼、川大智胜、乔治白等都是经典案例
5. 跟着游资走就是与虎谋皮，赚的必然是散户亏的钱
6. 投资忌讳扎堆，人多的地方必然有额外泡沫和溢价
7. 股票亏损按百分比计算，用危险方法玩只要被套一次就一夜回到解放前
8. 理解这个原理后，就不会被这种事情坑了
